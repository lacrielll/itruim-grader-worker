# Example Lab: Python и NumPy

Небольшая публичная лабораторная для демонстрации интеграции с
`grader-worker`. Это сокращённый пример, а не реальная лабораторная курса.

## Что сделать

Реализуйте функции в `python_basics.py` и `numpy_tasks.py`. Директорию
`grader_contracts` изменять нельзя. Имена функций, входные contract objects и
типы результатов являются частью публичного контракта.

### Python

1. `count_vowels` — число латинских гласных `a, e, i, o, u` без учёта регистра.
2. `has_unique_characters` — встречается ли каждый символ не более одного раза.
3. `multiplicative_persistence` — число перемножений цифр до одной цифры.
4. `prime_factorization` — факторизация в формате `(n1**p1)...`; степень `1`
   не печатается.

### NumPy

1. `sum_prod` — сумма произведений batch матриц `(p,n,n)` на соответствующие
   векторы `(p,n,1)`.
2. `binarize` — значения строго больше `threshold` становятся `1`, остальные `0`.

## Ограничения

- 1 CPU, 256 МБ RAM, до 120 секунд на проверку;
- repository не больше 10 МБ;
- без сети, файлового ввода-вывода, запуска процессов и динамического исполнения;
- решения проверяются на примерах, граничных случаях и разумных размерах входа.

После deterministic tests LLM-review может оценить читаемость и понимание
реально использованных конструкций. Знание внутреннего устройства NumPy не
требуется.

## Локальная самопроверка структуры

Если рядом установлен публичный `grader-worker`:

```bash
grader-worker precheck --assignment lab1 --path .
```

Команда проверяет структуру и публичную policy, но не раскрывает и не запускает
закрытые тесты production-курса.

Публичный сокращённый grader этого примера находится в [`../../graders/lab1`](../../graders/lab1). Полный цикл запуска платформы и worker описан в [корневом README](../../README.md).
